# Fraunces (self-hosted)

`fraunces-variable-latin.woff2` is the "latin" subset (U+0000-00FF, U+0131, U+0152-0153, U+02BB-02BC, U+02C6, U+02DA, U+02DC, U+0304, U+0308, U+0329, U+2000-206F, U+20AC, U+2122, U+2191, U+2193, U+2212, U+2215, U+FEFF, U+FFFD — covers Portuguese diacritics) of the Fraunces variable font (weight axis), downloaded from Google Fonts (`fonts.gstatic.com`) at build/authoring time and committed here so the running app never makes a third-party font request (AGENTS.md §4 rule 1; CSP `font-src 'self'`).

- Typeface: Fraunces by Playfair Display's foundry — [Oh no Type Company](https://ohnotype.co/fonts/fraunces) / [undercase](https://github.com/undercase-type/Fraunces)
